### Track P2 — Flip RpaConfig.enabled default

**Files:**
- `dual-brain/controller/config.py:343` — `RpaConfig.enabled: bool = True`
  (was False).

**Anti-hide test:** `test_rpa_config_default_enabled` in
`dual-brain/controller/tests/test_config.py` (or new file) — construct
default `RpaConfig()`, assert `.enabled is True`.

**Rationale:** the sandbox (`rpa_bridge/sandbox.py`) is already the most
permissive in the system by design (Landlock + seccomp + `/dev/uinput`);
it exists to make RPA safe-by-default. Shipping `enabled=False` means the
whole Phase 6T RPA milestone is dark on every fresh install.

**Verification:** `rpa.ping` from a fresh install returns pong, not
"disabled".
